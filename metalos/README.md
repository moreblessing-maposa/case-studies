# MetalOS

> Yard operating system and public website for a scrap-metal trading and logistics business.

**Status:** Completed &nbsp;·&nbsp; **Years:** 2025 &nbsp;·&nbsp; **Role:** Business analysis → build
**Domain:** Operations system + website &nbsp;·&nbsp; **Source code:** private (client work)

## The problem

A scrap-metal trading operation reconciled weighbridge tickets, grading, pricing and payouts by hand at day end.

## The solution

An internal system that records intake, grading, pricing and settlement once, plus a public website for the buying and collection service.

## My contribution

Business analysis, process design, and build of the system and website.

## Result

- Day-end reconciliation runs inside the system
- One record from weighbridge to settlement
- A credible public face for the business

## Built with

`React` · `TypeScript` · `Supabase`

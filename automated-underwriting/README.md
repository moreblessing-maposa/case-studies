# Automated Underwriting

> Random-forest model that recommends Accept, Load or Decline for life and funeral underwriting, served through an API.

**Status:** Prototype &nbsp;·&nbsp; **Years:** 2025 &nbsp;·&nbsp; **Role:** Data → machine learning
**Domain:** Life & Funeral Insurance &nbsp;·&nbsp; **Source code:** private

## The problem

Life and funeral applications need a consistent first decision: accept, load or decline.

## The solution

A random-forest model in a scikit-learn pipeline that recommends Accept, Load or Decline, served through a FastAPI endpoint.

## My contribution

Generated a realistic synthetic underwriting dataset, engineered occupation-risk and relationship-strength features, trained the model and built the API.

## Result

- Consistent, repeatable first recommendation
- Risk features grounded in real underwriting practice
- Any system can call it through the API

## Built with

`Python` · `pandas` · `scikit-learn` · `Random Forest` · `FastAPI`
